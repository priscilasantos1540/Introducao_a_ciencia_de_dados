A PNS é uma pesquisa domicilar ampla. Ela investida:
1. Condições de saúde;
2. Acesso e utilização dos serviços de saúde;
3. Doenças Crônicas;
4. Fatores de Risco;
5. Características sociodemográficas;
6. Diversos outros aspectos relacionados á saúde da população.
